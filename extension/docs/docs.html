📄 Kho tài liệu tham chiếu

Dán tài liệu bạn sẽ bị hỏi đến (hợp đồng, spec, CV/JD, ghi chú…). Khi câu hỏi vang lên trong cuộc họp, Copilot hiện trích đoạn khớp + câu trả lời đề xuất chỉ từ tài liệu này. Tất cả nằm trên máy bạn.

⭐ Copilot là tính năng Pro — bạn vẫn soạn kho tài liệu được, nhưng cần license key (popup → Nâng cao) để thẻ trả lời chạy trong cuộc họp.
